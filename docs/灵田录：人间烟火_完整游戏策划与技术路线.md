# 二、世界观设定

## 2.1 背景

天地灵气衰退，修仙宗门没落。  
玩家被逐出宗门，来到荒废的「青禾村」。

---

## 2.2 世界规则

### 灵田系统

- 普通农田 → 灵田
- 作物 → 灵植（可炼丹）

---

### 修炼方式

```text
种田 → 收灵植 → 炼丹 → 提升修为
```

---

### 人情社会

- NPC有记忆
- NPC会改变行为
- 玩家影响整个村庄生态

# 七、第一阶段（生存期）功能细化与开发落地

## 7.1 阶段目标（可验收）

- 开垦可种植地块（目标：12块）
- 完成基础播种/浇水/收获闭环（累计收获20单位）
- 通过售卖灵植获得第一桶金（目标：1000）

## 7.2 玩家日常循环（第一阶段）

```text
清晨恢复体力 → 开垦/播种 → 白天浇水与社交 → 收获并售卖 → 夜晚推进到次日
```

## 7.3 本阶段代码模块（已开始实现）

- `CropSystem`：新增地块状态（未开垦/已开垦/种植中/可收获）与浇水影响成长。
- `InventorySystem`：支持容量与物品增减。
- `PlayerStatusSystem`：支持金币与体力消耗/恢复。
- `EconomySystem`：新增售卖接口与金币收益事件。
- `SurvivalPhaseSystem`：追踪“开垦数、收获数、金币”并判定第一阶段完成。

## 7.4 第一阶段里程碑

- M1（当前）：核心系统骨架与事件流打通。
- M2：接入Tilemap交互与工具动作（锄地壶水镰刀）。
- M3：接入UI（任务追踪、体力条、背包、售卖面板）。
- M4：加入第一阶段剧情节点（村长引导、首次集市）。
